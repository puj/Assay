# Assay — the experiment contract

Assay is a [Project Nothing](https://www.projectnothing.ai) experiment. The
canonical contract lives in the umbrella repository as
`docs/experiments/assay.md`; this is its mirror, kept so whoever finds this
repository knows what was promised and how it will be judged.

**The question.** Will a stranger install a browser extension in order to
*select* passages of an AI answer — and then send a selection back as a prompt
at least once?

**The hypothesis.** AI chat interfaces are built around one verb, prompt; the
editorial step — deciding which three sentences deserve a second look — has no
interface, and the copy-paste tax is high enough that turning selection into a
gesture gets used. *False if* fewer than 50 installs arrive inside the timebox,
or the stores' active-user counts end below half of installs.

**The commercial hypothesis.** Free, one shape. The only sellable thing — an
archive with sync — is a server this contract does not build.

**The bet.** €20 ceiling; 336 hours from the campaign's last post.

**The kill condition.** Fewer than 50 installs across both stores at the end of
the timebox, or fewer than 25 store-reported active users. Never renegotiated.

**The funnel.** impressions = listing views + social impressions · visitors =
site requests · activations = installs · shares = reposts + raw-script installs
· checkouts / purchases = none, on purpose. The extension has no analytics; the
store dashboards are the instrument.

**The attention ask.** 45 seconds (a 23-second demo and the install decision);
claims `interesting`.

*This is an experiment. It might be gone next month.*
