DeepDive

Editorial selection over your AI conversations. Mark the passages that catch your attention while reading, annotate them, and send them back as one deep-dive prompt — no copy-paste, no talking, no API.

The garbage collector becomes the allocator of life. Creators rarely bear the cost of rejection. The missing primitive is not annotation; it’s accumulating several annotations before responding. Selection is probably the higher-bandwidth input modality.

Works on chatgpt.com and claude.ai in a mobile browser. Fragments persist across responses and conversations, stored only on your phone. Your existing subscription does all the inference.

Firefox + Tampermonkey Recommended

One-time setup, about five minutes. The script then loads automatically on every visit.

  1. Install Firefox from the Play Store, if you don’t have it.
  2. In Firefox: menu ⋮ → Add-ons (or Extensions) → search Tampermonkey → Add. Violentmonkey works identically if you prefer it.
  3. Come back to this page in Firefox and tap the button below to copy the script.

  4. Menu ⋮ → Add-ons → Tampermonkey → open its Dashboard → tap + (create new script) → long-press in the editor, Select all, Paste → save (file icon or Ctrl-S).
  5. Open chatgpt.com in Firefox and sign in. Select any sentence in a reply — the ＋ Collect chip appears.

Chrome bookmarklet Fallback

No extension needed, but you tap it once per visit to activate.

  1. Tap to copy the bookmarklet.

  2. In Chrome, bookmark any page (⋮ → ☆), then ⋮ → Bookmarks → edit it: name it dive and paste over the URL. If Chrome strips the javascript: prefix when pasting, retype those 11 characters at the front.
  3. On chatgpt.com, type dive in the address bar and tap the bookmark suggestion. The pill and chip appear; tapping it again opens your collected fragments.

Using it

Select a passage in any reply → tap ＋ Collect. Repeat as you read — across replies, even across conversations.

Tap the Deep dive pill to review: add a short note to any fragment, delete strays, expand truncated text with a tap.

↗ Explore together writes the synthesized prompt straight into the composer. Review it, then send. If injection is ever blocked, it lands on your clipboard instead.

Clear and sent batches are restorable from the empty sheet, so nothing is lost by accident.

Everything stays in your browser’s local storage, per site. Nothing is sent anywhere except the prompt you choose to send.
