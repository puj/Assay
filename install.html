Select → collect → synthesize

DigBoard

Editorial selection over your AI conversations. Tap the sentences that catch your attention while reading, annotate them, and send them back as one payload — no boilerplate, no copy-paste, no API.

The garbage collector becomes the allocator of life. Creators rarely bear the cost of rejection. The missing primitive is not annotation; it’s accumulating several annotations before responding. Selection is probably the higher-bandwidth input modality.

＋ Add  ✎ Note  ✕ Deep dive 3

Works on chatgpt.com and claude.ai in a mobile browser. Each conversation keeps its own fragment list, stored only on your phone and persisting across visits; export to .md/.txt at any time. Your existing subscription does all the inference. Three ways to run it — all the same payload.

Firefox + Tampermonkey Recommended

One-time setup, about five minutes. The script then loads automatically on every visit.

  1. Install Firefox from the Play Store, if you don’t have it.
  2. In Firefox: menu ⋮ → Add-ons (or Extensions) → search Tampermonkey → Add. Violentmonkey works identically if you prefer it.
  3. Come back to this page in Firefox and tap the button below to copy the script.

  4. Menu ⋮ → Add-ons → Tampermonkey → open its Dashboard → tap + (create new script) → long-press in the editor, Select all, Paste → save (file icon or Ctrl-S).
  5. Open chatgpt.com in Firefox and sign in. Tap any word in a reply — it highlights and the ＋ Add bar appears; tap the highlight to widen it.

Chrome bookmarklet Fallback

No extension needed, but you tap it once per visit to activate.

  1. Tap to copy the bookmarklet.

  2. In Chrome, bookmark any page (⋮ → ☆), then ⋮ → Bookmarks → edit it: name it dive and paste over the URL. If Chrome strips the javascript: prefix when pasting, retype those 11 characters at the front.
  3. On chatgpt.com, type dive in the address bar and tap the bookmark suggestion to activate tap-to-collect; running it again opens your collected fragments.

Extension package For distribution

The same payload as a WebExtension — no userscript manager needed. extension/ in the repo holds the source; digboard-extension.zip is the packaged build, and store/ has the listing copy, screenshots and submission checklist.

  1. Desktop Chrome/Edge, today, free: chrome://extensions → Developer mode → Load unpacked → pick the extension/ folder. Chrome on Android doesn’t run extensions at all — that’s why mobile routes through Firefox or the bookmarklet.
  2. Real Firefox Android extension: create a free developer account at addons.mozilla.org (no fee, unlike Chrome’s one-time $5) and submit digboard-extension.zip as a listed add-on. Automated review typically approves simple extensions within minutes to hours; a follow-up human review can occasionally take days. Once live, it installs on regular Firefox for Android with one tap from its add-on page — set the listing’s visibility to Invisible so only people with the direct link find it.
  3. Private alternative (no listing): submit as unlisted/self-distributed instead — signing is automated, usually minutes — and you get a signed .xpi file. On Firefox for Android: Settings → About Firefox → tap the logo five times to unlock the debug menu, then Settings → Install extension from file.

Using it

Tap a word in any reply — it highlights, with a small bar: ＋ Add collects it, ✎ Note annotates it now (choose whether the note sits before or after the quote). Tap the highlight to widen it — word → sentence → paragraph → back to the word. Tap other words in the same reply to grow the selection toward them, word by word — across paragraphs too. To start over: ✕ on the bar, or tap a different reply or empty space. Long-press selection still works for arbitrary spans.

Each fragment gets the next of six rotating highlight colors, and collected marks stay tinted on the page while you keep reading. Tap the Deep dive pill to flip between the fragment view and the conversation — the page stays scrollable behind it and taps keep collecting. In the list: annotate later, flip a note between before/after, delete strays, expand truncated text with a tap. Each conversation keeps its own list (fragments collected in a brand-new chat follow it once it gets its address); a shared cross-conversation list may come later.

↗ To composer writes just your fragments and annotations into the composer — no added prompt text; your annotations carry the intent. Review, then send. If injection is ever blocked, it lands on your clipboard instead.

⬇ .md / ⬇ .txt download the entire current conversation to your phone — named digboard-<chat title>-<timestamp> — with your collected fragments and notes appended — nothing is sent or cleared. On a very long thread, scroll to the top first: the sites load older messages lazily, and the export captures what’s on the page.

Clear and sent batches are restorable from the empty sheet, so nothing is lost by accident.

Everything stays in your browser’s local storage, per site. Nothing is sent anywhere except the prompt you choose to send.
